# 문제가 생겼을 때

먼저 실제 자료를 외부로 보내지 마세요. 버전과 오류 상태, 클릭 순서를 기록하고 가상자료로 재현합니다. 아래 해결을 해도 문제가 남으면 작업을 백업하고 기관 담당자에게 알립니다.

| 현상 | 뜻과 해결 순서 |
|---|---|
| `runtime\python.exe is not recognized` | 예전 스크립트가 동봉 Python을 찾거나 실행하지 못함. Python을 별도로 설치할 필요 없음. 0.1.2 단일 EXE를 사용. ZIP 방식이면 모두 압축 풀기 후 runtime 폴더·보안제품 격리 여부 확인 |
| Python 오류 뒤 관리자 금지 문구 | 0.1.1의 공통 실패 문구가 부정확했음. 실제 관리자 토큰 판정으로 단정하지 말 것. 0.1.2는 누락·변조·실행 오류·권한을 따로 안내 |
| EXE의 실행 준비 실패 | 사용자 로컬 폴더 쓰기 권한·1GB 이상 여유 공간·실행 허가·고정 로컬 디스크 여부 확인. 관리자 실행으로 해결하지 않음 |
| 기존 실행 파일 누락·변경 | 파일별 해시 확인 실패. 보안제품 격리·변조 원인을 담당자가 확인. 자동 재생성하지 않으며, 차단을 피하려고 무조건 삭제·재실행하지 않음 |
| EXE 실행 뒤 화면 시작 실패 | 안내창에 표시한 로컬 startup 로그를 기관 안에서 확인. 로그를 외부로 보내지 말고 버전·오류 종류·가상 재현만 전달 |
| 프로그램 내부에는 작업 저장 불가 | 자동 준비 폴더와 작업을 분리해야 함. 기관 승인 별도 작업 폴더에 프로젝트·백업 생성 |
| 관리자 권한 실행 차단 | 현재 창을 닫고 일반 사용자 바탕화면에서 0.1.2 EXE를 더블클릭. 바로가기·호환성의 관리자 실행 설정 해제. 기관 정책 때문에 항상 관리자면 담당자가 일반 계정을 준비해야 함 |
| 권한 확인 실패 | 자료를 열기 전에 중단함. 관리자 실행으로 우회하지 말고 기관 담당자에게 오류 종류를 확인 요청 |
| PowerShell·SmartScreen 차단 | 기관 반입·서명 정책 문제일 수 있음. 보안 기능을 끄거나 실행정책을 우회하지 말고 담당자에게 확인 |
| 방화벽 규칙 없음·비활성 | 담당자만 방화벽설정_기관관리자전용.cmd를 승인된 관리자 계정으로 실행. 폴더를 이동했다면 새 경로에 재설정. 기관 정책이 막으면 중단 |
| DLL을 못 찾음·창이 바로 닫힘 | EXE 방식이면 시작 로그, ZIP 방식이면 전체 압축 해제, 공통으로 Windows 64비트 여부 확인. PACKAGE_MANIFEST 확인. 동봉 런타임 누락 또는 실기기 호환성 문제를 기록 |
| 파일 처리 실패 | 파일 목록의 이유를 확인. 손상·암호·50MiB 초과·시간 제한·압축 구조 문제 가능. 한컴/Excel로 기관 안에서 원본 상태 확인 후 정정 파일 재수령 |
| HWP 미지원 | HWP 5 텍스트만 제한 추출. 표 의미 자동 해석은 아직 미지원. 직접 원문을 확인할 수 없으면 보류 |
| 새 양식 | 실제 양식은 검증 전. 표식만 고쳐 자동 지원인 것처럼 만들지 말고 수동 근거 또는 별도 양식 개발 필요 |
| 단위 불명 | 문서의 단위 표기·열 머리글 확인. 확인된 단위를 연결 화면에서 이유와 함께 입력. 알 수 없으면 보류 |
| 연결 불명 | 8개 키 누락 또는 사용자 확인 전. 숫자 같다는 이유로 연결 금지 |
| 중복·수정본 | 근거를 비교하고 기관 규칙으로 채택. 채택하지 않은 근거는 이유를 써서 제외. 원본 삭제 금지 |
| 수식·오래된 계산 | 모든 수식은 보류. 원본 사본을 유지하고 승인된 로컬 도구로 계산·검증한 정정 제출 자료를 별도 수령. 이 시험판은 재계산하지 않음 |
| 승인 버튼이 거부됨 | 판정이 정확 일치/변환 후 정확 일치인지 확인. 경고·누락·다중 후보 해결 전 승인 불가 |
| 승인했는데 재검토 필요 | 새 근거, 단위, 키, 채택, 규칙, 원본 변경으로 기존 승인이 무효화됨. 근거를 다시 확인하고 개별 재승인 |
| 엑셀 저장 실패 | 남은 공간·폴더 쓰기 권한·Excel 잠금·보안제품 확인. 이전 정상 출력은 유지. 새 이름으로 다시 출력 |
| 숫자 셀에 초록 표시 | 정확한 문자열로 저장해서 Excel이 숫자 모양 텍스트라고 알리는 것. 큰 숫자를 무작정 숫자 셀로 변환하면 반올림될 수 있음 |
| 강제 종료·정전 | 재실행 후 파일 상태·출력 이력 확인. 처리 중이던 파일/출력은 실패 표시. 재처리 전 백업. 이전 정상 결과와 비교 |
| 다른 창에서 사용 중 | 같은 프로젝트의 다른 프로그램 창을 닫음. .lock을 임의 삭제해 동시에 편집하지 않음 |
| 해시 불일치 | 원본 사본이 바뀌었거나 손상됨. 승인·출력 중단. 정상 백업을 새 폴더로 복구하고 비교 |
| 백업 복구 실패 | 기준 해시·남은 공간·지원 DB 버전 확인. 기존 작업에 덮어쓰지 않음. 다른 정상 백업과 해당 프로그램 버전 사용 |
| 폴더 가져오기 취소 | 현재 파일 뒤 멈춤. 남은 파일은 미처리. 같은 제출 폴더를 다시 선택하면 기존 파일 중복 집계 없이 이어짐 |

작업 폴더의 `.pending-` 파일은 비정상 종료 중 남은 임시 결과일 수 있습니다. 다른 창에서 작업 중이지 않은지 확인하고 백업합니다. 정상 출력이 확인되기 전에는 임시파일을 최종 결과로 사용하지 않습니다. 삭제 여부는 기관 자료관리 절차를 따릅니다.

지원하지 않는 기능을 설정 한 줄로 억지로 켜지 마세요. 실제 최종 양식·계산식·OCR·암호파일은 별도 개발과 오프라인 검증이 필요합니다.

일반 권한에서 프로젝트 쓰기가 거부되면 관리자 실행으로 해결하지 않습니다. 담당자에게 해당 작업 폴더의 접근권한만 조정받거나 승인된 사용자 로컬 폴더로 전체 프로젝트를 복사합니다. Everyone 전체 제어나 PC 전체 권한 완화는 필요하지 않습니다.
