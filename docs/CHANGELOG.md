# 변경 기록

## 0.1.1 — 2026-10-31

- Windows 일반 사용자 실행만 허용. 관리자 토큰 또는 권한 확인 실패 시 자료를 열기 전에 중단. 자동 권한 상승 없음.
- 화면·프로젝트 열기·읽기 프로세스·가상시험에 권한 검사 적용.
- 관리자용 방화벽 도구는 운영체제 설정만 수행하며 예산 프로그램을 시작하지 않음. 평소 실행에서는 이 도구를 호출하지 않음.
- 가상시험 결과를 일반 사용자 LocalAppData에 저장. 업무 실행은 설치 폴더에 쓰기 권한을 요구하지 않음.
- 새 프로젝트의 이름이 exports로 잘못 저장되던 문제 수정. 대조 상세 내용을 한국어로 표시.
- 실제 Linux 실행 화면 5장과 시연 안내 추가. Windows 실기기 검증은 계속 미실시.

DB 구조 1·가상규칙-1 유지, DB 변환 없음. 비교·단위·승인 조건은 변경하지 않음. 이전 0.1.0 실행 묶음은 새 권한 정책에 맞지 않으므로 0.1.1을 사용해야 함.

## 0.1.0 — 2026-10-31

처음 만든 시험판입니다. Windows 11 64비트 우선, Windows 10 64비트 설계 대상입니다. Linux에서 기능 검증을 수행했고 Windows 실기기 실행은 미검증입니다.

- 로컬 데스크톱 화면, SQLite 프로젝트, 원본·작업 사본, 해시·처리 이력.
- 가상예산-v1 HWPX/XLSX 구조 규칙. HWP 5 텍스트 레코드 제한 읽기.
- 수동 연결, 정확한 Decimal 비교, 명시 단위 변환, 개별 승인·보류·제외.
- 중복·수정본 보류와 관련 승인 무효화, 규칙 변경 이력.
- long/wide 초안·시험용 승인 데이터, 출처·미해결·부서현황·출력 스냅샷.
- 백업·복구, 동시 열기 방지, 배치 취소, 손상·구조·크기 제한.
- Python 네트워크 기능 차단과 Windows 로컬 방화벽 설정 스크립트.
- 오프라인 Windows 런타임 포함 묶음과 가상시험 도구.

DB 구조 버전: **1**. 이전 버전에서의 자동 DB 변환: **없음**. 기본 양식·규칙: **가상예산-v1 / 가상규칙-1**. 실제 업무 양식은 모두 재검증 대상입니다. 새 자료·규칙·연결 변경으로 영향을 받은 승인은 재검토해야 합니다.

미지원: 공식 최종본·실제 제출 셀 매핑, HWP 표 자동 의미 추출, OCR, XLS/XLSM, 수식 재계산, 자동 사업 연결·합계·차액·비율 산식, 예외 승인 최종본, 다중 사용자 권한/전자서명. 보안 감사·Windows 인증·모든 미래 문서 무오류 보증은 수행하지 않았습니다.
