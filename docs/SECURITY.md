# 오프라인과 자료 보호

## 외부 연결이 없는 구조

실행 화면은 PySide6의 데스크톱 화면입니다. 웹서버, 브라우저 접속, 외부 로그인, API 키, GPT, OCR 서비스, 자동 업데이트, 사용 통계, 원격 오류 전송이 없습니다. 프로그램은 로컬 파일과 SQLite DB만 사용합니다. 링크를 눌러 인터넷 페이지를 여는 화면도 없습니다.

업무 모듈을 불러오면 Python의 네트워크 소켓 기능을 차단하는 추가 검사가 작동합니다. 소켓은 인터넷 연결에 사용하는 기능입니다. 이 검사는 Python 수준이며 모든 네이티브 라이브러리나 PC 전체를 통제하는 보안 경계는 아닙니다. Windows 설정 스크립트는 동봉한 python.exe와 pythonw.exe 각각에 모든 프로필의 입·출력 차단 방화벽 규칙을 추가합니다. 다른 프로그램의 기존 규칙은 건드리지 않습니다. 방화벽 정책이 기관 정책에 의해 적용되지 않으면 실행을 중단하고 담당자가 확인해야 합니다.

## 관리자 권한과 망분리

0.1.1은 Windows 프로세스의 TokenElevation을 확인하고 **관리자 권한이면 실행을 차단**합니다. 권한 확인에 실패해도 중단합니다. 화면 진입점뿐 아니라 프로젝트를 여는 기능, 문서 읽기 프로세스, 가상시험에도 검사를 적용합니다. 일반 실행은 관리자 암호를 요구하거나 UAC 권한 상승을 요청하지 않습니다. 관리자 그룹 계정이라도 상승되지 않은 일반 토큰으로 실행하면 허용합니다. UAC를 꺼 항상 관리자 토큰이 되는 PC에서는 차단되므로 기관 담당자가 일반 사용자 계정·정책을 준비해야 합니다.

관리자용 방화벽 도구는 운영체제 규칙만 설정하고 예산 처리 코드나 동봉 Python을 실행하지 않습니다. 평소 실행.cmd에서는 이 도구를 호출하지 않습니다. 따라서 앱의 시작 성공만으로 Windows 방화벽의 현재 상태가 검증됐다고 해석하면 안 됩니다. 기관 담당자가 별도 확인해야 합니다.

이 조치는 관리자 권한으로 인한 추가 접근을 막도록 한 것입니다. 일반 사용자에게 이미 허용된 파일 접근까지 제한하는 완전한 샌드박스, 사용자 인증, 전자결재 기능은 아닙니다. Windows 실기기에서의 토큰·방화벽 시험은 아직 필요합니다.

프로그램이 외부 통신을 하지 않는 것과 PC가 완전히 망분리된 것은 다릅니다. 네트워크 케이블·무선·기관 망 구성·원격 접속·동기화 프로그램은 기관 관리자가 관리해야 합니다. 이 프로그램은 다른 프로그램의 인터넷·원격 접속을 막지 않습니다. 방화벽 규칙은 설치 폴더의 실행 파일 경로에 적용됩니다. 폴더를 이동하면 그 위치에서 다시 설정해야 합니다.

## 수행한 통신 시험

- Linux에서 인터넷 인터페이스가 없는 네트워크 공간을 따로 만들었습니다. loopback만 존재함을 확인한 뒤 기능 시험·화면 시험·가상자료 취합과 복구를 실행했습니다.
- 네트워크가 허용되는 별도 실행에서는 `strace`로 업무 처리 자식 프로세스까지 네트워크 시스템 호출을 관찰했습니다. 결과와 범위는 TEST_REPORT.md에 기록합니다.
- Windows PC의 방화벽 적용, Qt/Windows 자체 동작, 차단된 연결 시도 관찰, 물리 망분리는 아직 확인하지 않았습니다. LOCAL_ACCEPTANCE.md를 따르세요. 단순히 연결이 차단되어 성공하지 않았다는 이유로 ‘시도 없음’이라고 보고하면 안 됩니다.

## 문서 입력 방어

문서의 매크로·스크립트·OLE 객체·외부 링크를 실행하지 않습니다. 한컴/Excel 자동화도 하지 않습니다. XLSX는 저장된 구조만 읽고 계산하지 않습니다. HWPX XML의 외부 개체 선언을 거부합니다. ZIP 내부의 `../`, 절대 경로, 중복 경로, 심볼릭 링크, 암호화 항목을 거부합니다. 압축 내용을 외부 경로로 풀지 않습니다.

기본 입력 제한은 파일당 50MiB, ZIP 총 해제 200MiB, 항목 5,000개, 개별 XML 20MiB, XML 단일 문자열 10,000자, XML 깊이 80, XML 요소 300,000개, XLSX 셀 범위 100,000개, 파일별 추출 근거 20,000개·총 3,000,000자, 읽기 프로세스 30초입니다. 높은 압축률도 제한합니다. 파일은 별도 프로세스에서 읽고 시간 초과 시 중단합니다. 이 프로세스는 같은 사용자 권한이며 완전한 운영체제 샌드박스가 아닙니다. 메모리·악성 문서의 모든 공격을 막는다고 보장하지 않습니다.

XLSX 내보내기는 모든 셀을 문자열 타입으로 저장합니다. `=...`, `+...`, `@...`로 시작하는 내용도 수식으로 저장하지 않습니다. 출력 후 파일을 다시 열어 수식 셀이 없는지 검사합니다. 숫자를 텍스트로 저장하므로 Excel의 15자리 제한으로 큰 예산 값이 잘리는 문제를 피하지만, 산술 합계는 별도 승인된 절차가 필요합니다.

## 자료 저장 위치와 보호

| 위치 | 내용 |
|---|---|
| 프로젝트/project.db | 파일 정보, 값, 규칙, 수동 연결, 승인, 이력, 출력 스냅샷 |
| 프로젝트/originals | 관리용 원본 사본. 읽기 전용 속성·해시 확인 |
| 프로젝트/work | 읽기용 복사본. 재처리 때 원본 사본으로 다시 만듦 |
| 프로젝트/exports | 결과 엑셀·중단 시 임시 출력 |
| 사용자가 고른 백업 ZIP | DB, 원본, 정상 출력, 복원에 필요한 규칙·이력 |
| 가상시험 결과 폴더 | 가상 문서, 시험 DB, 백업, 측정 결과 |

이력은 DB 내부에 저장합니다. 원문·사업명·수치도 들어 있으므로 DB와 로그성 자료 전체를 업무자료로 취급합니다. 내보낸 근거 시트에도 원문이 포함됩니다. 임시파일은 정상 실패 처리 때 제거하지만 강제 종료 후 `.pending-` 파일이 남을 수 있습니다. 작업 중이 아닌지 확인하고 백업한 뒤 기관 절차에 따라 처리하세요.

기본 암호화·DB 비밀번호는 없습니다. 기관의 디스크 암호화(BitLocker 등), 폴더 접근권한, 백업 보관 규칙을 적용해야 합니다. 프로그램 폴더와 작업 폴더에 불필요한 쓰기 권한을 주지 마세요. 프로그램 파일을 바꿀 수 있는 사람은 권한 검사 코드도 변조할 수 있으므로 설치 폴더의 쓰기 권한을 제한해야 합니다. 일반 사용자는 프로그램을 읽고 실행할 권한, 별도 작업 폴더에는 자기 작업에 필요한 수정 권한만 갖도록 기관이 설정합니다. 동기화 폴더나 네트워크 드라이브·USB는 기관이 허용한 경우만 사용하세요. UNC 공유 경로는 프로젝트 생성 시 거부하지만 모든 동기화·매핑 경로를 완벽히 식별하지는 못합니다.

SHA-256은 변경을 알아내는 도구이지 변경을 못 하게 하는 장치나 전자서명이 아닙니다. DB와 원본·기준 해시를 모두 바꿀 수 있는 관리자를 상대로 위변조 방지를 보장하지 않습니다. 잠금도 프로그램의 동시 사용을 막는 기능이며 관리자에 대한 보안 장벽은 아닙니다.

## 설치 묶음 확인

기관이 신뢰하는 별도 경로로 배포 파일 기준값을 확인하세요. Windows의 시작 버튼을 눌러 PowerShell을 열고 아래처럼 입력합니다. 실제 ZIP 위치에 맞춰 경로를 바꿉니다.

```powershell
Get-FileHash -Algorithm SHA256 'C:\반입\BudgetOffline-0.1.1-Windows-x64.zip'
```

출력된 Hash를 공식적으로 전달받은 기준과 비교합니다. ZIP과 같은 곳에서 받은 해시만으로 배포자 신원을 확인할 수는 없습니다. `PACKAGE_MANIFEST.json`은 묶음 내부 파일별 해시입니다. 실행 스크립트가 이를 확인하지만 독립된 코드 서명을 대신하지 않습니다. 이 시험판의 앱·스크립트는 코드 서명되어 있지 않습니다.

PowerShell 실행 제한·SmartScreen·기관 보안제품이 실행을 막으면 보안 기능을 끄지 마세요. 담당자에게 반입·서명·허용 절차를 요청하세요. 개발자가 업무자료나 로그를 자동으로 받는 기능은 없습니다.

## 보관·삭제·문제 전달

보관기간은 아직 기관 규칙이 정해지지 않아 프로그램이 자동 삭제하지 않습니다. 마감 후 원본·DB·출력·백업·임시파일의 보존 기간을 정하고 담당자가 삭제합니다. 일반 삭제·휴지통 비우기는 SSD 등에서 안전한 완전 삭제를 보장하지 않습니다. 기관의 저장장치 폐기·암호화 키 처리 절차를 따르세요.

오류를 개발자에게 알릴 때 실제 파일·DB·화면·전체 로그를 보내지 않습니다. 처음부터 가상자료를 만들고 버전, 오류 종류, 재현 클릭 순서만 전달합니다. 숫자 몇 개를 가렸다고 문서 속성·숨김 시트·주석까지 제거되었다고 믿으면 안 됩니다.
