# 실제 업무 PC에서의 도입 전 확인

이 표는 아직 완료되지 않은 현장 검증 기록지입니다. 담당자가 기관 내부에 보관합니다. 실제 자료·결과·로그를 외부 AI나 개발 서버에 보내지 않습니다.

## 순서대로 시험하기

1. 새 Windows 시험 폴더에서 ZIP 무결성과 관리자·방화벽 설정을 확인합니다. 일반 권한 실행이 거부되는지도 확인합니다.
2. 네트워크를 기관 절차로 실제 차단하고 가상시험.cmd, GUI 첫 실행, 6개 정상 파일 가져오기, 연결, 승인, 초안·승인 출력, 백업 복구를 수행합니다.
3. 기관이 허용하는 별도 관찰 환경에서 Windows 방화벽 로그·보안 모니터 등으로 python.exe/pythonw.exe와 자식 프로세스의 연결 시도를 확인합니다. 성공 연결뿐 아니라 **차단된 시도**도 확인합니다. 실제 업무자료는 쓰지 않습니다. 결과·프로세스·시각을 내부 기록합니다.
4. 한컴오피스에서 직접 만든 무민감 가상 HWP/HWPX와 Excel XLSX를 사용합니다. 텍스트 파일의 확장자만 바꾸지 않습니다. 표·병합·반복 머리글·여러 사업·빈칸·수식·암호·손상 조건을 포함합니다.
5. 사람이 별도로 정답을 작성합니다. 숫자와 의미, 단위, 원문 위치, 기대 보류 사유를 기록합니다. 동봉 기대결과는 개발자가 만든 가상 규칙이며 사람이 업무 정답으로 검수한 자료가 아닙니다.
6. 기관 내부에서 실제 양식의 파일 역할을 구분합니다: 제출 한글, 제출 엑셀, 최종 취합 엑셀. 실제 파일을 개발용 대화로 전송하지 않습니다.
7. 필수 키·단위·감액·반올림·예산구분·전년 차액·집행률/사용률 산식을 확정합니다. 입력과 출력 양식이 같다고 가정하지 않습니다.
8. 최종 셀 매핑과 수식·서식·인쇄 설정을 보존하는 별도 구현·검증이 완료되기 전까지 공식 최종본은 사용하지 않습니다.
9. Excel로 출력 파일을 열어 long/wide/원문근거 연결과 문자열 숫자 보존을 확인합니다. 큰 숫자, 소수, 앞자리 0을 특히 확인합니다.
10. 수정본·파일 제외·키 변경·규칙 변경 뒤 재승인이 필요한지 확인합니다. 백업을 다른 새 폴더로 실제 복구합니다.

잘못된 자동 통과와 미승인 공식 반영은 시험에서 0건이어야 합니다. 추출 누락률·보류율·수동 작업량도 함께 기록하세요. 모든 자료를 보류했다는 것만으로 정확한 프로그램이라고 판단하지 않습니다. 기관 담당자의 제한된 검증과 별도 보안 검토 후 도입 여부를 결정합니다.
