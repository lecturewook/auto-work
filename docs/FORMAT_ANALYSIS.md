# 가상 양식 분석과 실제 확인 대기 항목

실제 문서를 받지 않았습니다. 아래 구분은 가상자료 설계를 위한 것으로 기관 양식의 최종 결정이 아닙니다.

| 역할 | 현재 가상 형식 | 읽는 구조 | 실제 확인 대기 |
|---|---|---|---|
| 제출 한글 | HWPX 가상 표 | 가상예산-v1 표식, 10개 머리글, 단순 행 | 실제 HWP/HWPX, 다단 머리글, 반복 표·본문·페이지 |
| 제출 엑셀 | XLSX 가상제출 시트 | A1 표식, 처음 100행 안 10개 머리글 | 여러 양식·필수 시트·실제 저장값·수식·숨김·외부참조 |
| HWP 읽기 보조 | HWP 5 이진 구조 시험 파일 | FileHeader/BodyText의 텍스트 레코드 | 한컴이 생성한 실제 파일·표 관계·렌더링 호환성 |
| 취합 보고서 | 새로 만드는 XLSX | long/wide/근거/미해결/이력/부서현황 | 입력 엑셀과 동일 양식인지 여부 |
| 최종 제출 양식 | 없음 | 쓰기 기능 잠김 | 허용 시트·셀·기존 값·수식·서식·인쇄 설정 |

가상 지표는 시행예산, 전년도예산, 집행률, 예산사용률입니다. 예산은 원화, 비율은 % 또는 명시적 비율입니다. 전년 대비 차액·집행률 산식을 임의로 정의하지 않았습니다. 제출된 각 지표를 비교하며, 사업총액과 소계·명세는 집계수준으로 구분합니다.

가상 정답은 `samples/기대결과.json`에 명시적으로 적었습니다. 정상자료는 3부서·6파일·12지표·24근거입니다. 각 근거를 확인하기 전에는 12지표 모두 연결 불명이어야 합니다. 확인 후 지표별 기대 표준값은 시행예산 1000000 KRW, 전년도예산 900000 KRW, 집행률 0.125 ratio, 예산사용률 0.60 ratio입니다. 값의 끝자리 0은 의미상 같은 수일 수 있으며 비교는 정확한 십진수로 합니다.

주의자료는 수정본, 수식, 숨김, 새 양식, 빈칸/0/대시/해당 없음/근사값/단위 없음, 손상, HWP 구조 시험을 담습니다. 해당 자료는 한컴오피스 호환성 인증용이 아닙니다. 가상 HWP/HWPX는 생성기의 구조 시험 산출물이며 실제 한컴 저장 문서의 완전성을 검증하지 않았습니다.

사람이 업무 정답을 검수한 결과물은 아직 없습니다. `LOCAL_ACCEPTANCE.md`에 따라 담당자가 기관 내부에서 정답을 별도로 작성하고 파일별 입력·출력 역할, 코드, 기간, 예산 구분, 단위, 반올림, 채택 규칙을 확정해야 합니다.
