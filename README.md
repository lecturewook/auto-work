# 예산 근거 대조 — 완전 오프라인 시험판 0.1.3

> 0.1.3 실행 방식: 단일 EXE를 그냥 더블클릭합니다. Windows에 일반 실행(asInvoker)을 명시했습니다. 높은 권한을 물려받으면 Windows의 UAC 연결 토큰, 같은 사용자 바탕화면 토큰, Windows 기본 사용자 제한 토큰 순서로 전환을 시도합니다. 전환 후보와 실제 자식 프로세스의 사용자·로그인 세션·상승 여부·무결성 수준·관리자 그룹·UI 접근 권한을 확인하고, 일반 권한인 경우에만 자료를 처리합니다. 전환 실패는 오류 코드를 표시하고 중단합니다. 아래의 단순 관리자 차단 설명은 이전 동작이며, ZIP의 실행.cmd에는 자동 전환 기능이 없습니다. Windows 보안 정책을 끄거나 변경하지 않습니다. Windows 11 실기기에서 자동 전환 성공 여부는 아직 미검증입니다.

이 프로그램은 부서에서 받은 한글·엑셀의 숫자를 근거와 함께 비교하는 **시험 프로그램**입니다. 원본 사본을 보존하고, 같은 업무 항목인지 사람이 확인한 뒤 단위를 맞추어 비교합니다. 정확히 같아도 사람이 승인해야 승인 데이터에 들어갑니다.

**실제 예산 업무의 최종 결과를 만들 수 있는 상태는 아닙니다.** 실제 양식·셀 매핑은 미확정이며 공식 최종본 출력은 코드에서 막았습니다. 실제 자료를 이 대화나 외부 사이트로 보내지 마세요.

**0.1.1부터 관리자 권한 실행을 차단합니다.** 예전 0.1.0 실행 묶음 대신 이 버전을 사용하세요. 권한 상승 요청이나 자동 관리자 재실행은 없습니다.

**Python 설치 없이 시작하려면 [빠른 실행 안내](docs/QUICK_START.md)를 보세요. 0.1.3는 EXE 하나를 더블클릭하는 방식이며 ZIP을 직접 풀 필요가 없습니다.**

## 무엇을 받았나요?

| 파일 | 용도 |
|---|---|
| `BudgetOffline-0.1.3-Windows-x64.exe` | **권장.** Python·Qt·프로그램을 모두 포함한 단일 실행 파일. 실행 중 다운로드 없음 |
| `BudgetOffline-0.1.3-Windows-x64.zip` | Windows용 Python·화면 라이브러리·프로그램·가상자료·문서를 포함한 압축 실행 묶음 |
| `BudgetOffline-0.1.3-source.zip` | 수정할 수 있는 프로그램 소스, 테스트, 빌드 도구, 문서 |
| `BudgetOffline-0.1.3-guides.zip` | Markdown 안내서와 실제 수행한 시험 결과 |
| `SHA256SUMS.txt` | 배포 파일의 내용 지문. 기관이 별도 경로로 확인한 기준과 비교하세요. |

Windows 묶음은 **Linux에서 조립·EXE 교차 빌드·파일 검증을 했으며 Windows 실기기 실행·관리자 권한·방화벽 명령은 아직 시험하지 않았습니다.** 코드 서명된 상용 설치 파일이 아닙니다. 기관 담당자가 가상자료로 먼저 확인해야 합니다. Python은 3.12.10, PySide6/Qt는 6.8.3입니다. 최신 보안 패치 확인과 기관 반입 검사는 별도입니다.

## 지금 가능한 것

- 이름 있는 프로젝트 생성·다시 열기, 여러 파일·폴더 가져오기, 파일별 실패 기록.
- 원본 사본·작업 사본 분리, SHA-256 확인, 동일 내용 재가져오기 차단.
- 가상 양식 HWPX/XLSX 표 읽기, 일반 양식의 셀·문단 근거 표시, 수동 연결.
- HWP 5의 텍스트 레코드 읽기 시도. **자동 표 의미 추출은 미지원 상태**로 표시.
- 정확한 십진수 계산, 명시적 단위 변환, 중복·수정본 보류, 개별 승인.
- 검토용 초안·시험용 승인 데이터 XLSX: long, wide, 출처, 미해결, 이력, 부서현황.
- 원본·DB·규칙·출력을 묶은 백업과 새 폴더 복구.

실제 양식 자동 인식, HWP의 표·페이지 재현, OCR, XLS/XLSM, 수식 재계산, 자동 사업 연결, 전년 대비 차액·집행률 계산식, 일괄 승인, 다중 사용자 동시 편집, 최종 제출 양식 기입은 제공하지 않습니다.

## 준비물

Windows 11 64비트를 우선 대상으로 만들었습니다. Windows 10 64비트도 설계 대상이지만 둘 다 실기기 검증 전입니다. 일반 사용자 계정과 기관의 실행 허가가 필요합니다. 방화벽 같은 PC 설정 변경은 기관 담당자가 별도로 수행합니다. 한컴오피스와 Excel은 원문을 사람이 확인할 때 사용합니다. 프로그램 자체는 두 프로그램을 자동 실행하거나 조종하지 않습니다.

기관이 허용한 **로컬 디스크 폴더**를 준비하세요. 예: 프로그램 `C:\BudgetTrial`, 작업 `C:\BudgetWork`. OneDrive, 공유 폴더, 바탕화면 자동 동기화, USB 사용은 기관 정책에 따릅니다. EXE는 사용자 로컬 폴더에 프로그램을 자동 준비합니다. 작업 폴더는 따로 선택하세요. 압축을 풀 공간과 작업 원본·작업 사본·백업 공간을 확보하세요. 작은 가상자료를 제외하고 필요한 공간은 실제 파일 크기에 따라 달라집니다.

## Windows에서 첫 실행

다음은 업무 PC에서 가상자료로 검증할 절차입니다. Windows 실기기 시험을 완료했다는 뜻은 아닙니다.

1. 기관이 허용한 절차로 **BudgetOffline-0.1.3-Windows-x64.exe**와 기준 해시를 받습니다. 기관 담당자가 망분리·반입·보안 정책을 확인합니다.
2. EXE를 로컬 폴더에 저장하고 **그냥 더블클릭**합니다. Python 설치나 명령어 입력은 필요 없습니다. 관리자 권한으로 실행하면 중단합니다.
3. **실행 준비** 창을 기다립니다. 내장 실행 환경을 사용자 로컬 폴더에 꺼내고 파일별 SHA-256을 확인합니다. 프로그램 준비 여유 공간 1GB 이상과 별도 작업 공간을 권장합니다. 다운로드·자동 업데이트는 하지 않습니다.
4. **가상자료로 시작**을 누르고 기관이 허용한 로컬 작업 폴더와 새 이름 `2026_가상시험`을 정합니다. 프로그램 내부에 프로젝트를 만들 수 없습니다.
5. 정상 가상자료 6개·근거 24개·업무 항목 12개와 부서·필수 항목 목록이 들어옵니다. 기존 프로젝트를 연 상태에서는 가상자료 시작을 차단하여 업무자료와 섞지 않습니다.
6. **연결·원문 근거**에서 한 행을 선택합니다. 아래 원문·위치를 보고 **연결 확인/수정**에서 키·단위를 확인하고 검토자·이유를 적습니다. 가상자료에서는 기존 키를 정답과 대조합니다.
7. 같은 지표의 한글·엑셀 근거를 모두 확인하면 **대조·승인·수정본**의 판정이 `변환 후 정확 일치` 또는 `정확 일치`가 됩니다.
8. 해당 행에서 **선택 항목 승인**을 누르고 검토자·이유를 기록합니다. **취합 미리보기 → 승인 데이터 저장**을 누릅니다.
9. 결과는 프로젝트의 `exports` 폴더에 `시험용승인데이터_식별번호.xlsx`로 생깁니다. 공식 최종본이 아닙니다.
10. 다음 실행도 같은 EXE를 더블클릭합니다. **프로젝트 열기**로 이전 작업을 이어갑니다. 실행 준비 경로·시작 로그·오류 해결은 [빠른 실행 안내](docs/QUICK_START.md)에 있습니다.

기관에서 폴더형 배포를 요구하면 ZIP도 제공합니다. 그때만 **모두 압축 풀기** 후 `실행.cmd`를 일반 더블클릭합니다. `runtime` 폴더가 바로 옆에 있어야 합니다. `python.exe`를 못 찾는 오류는 Python을 별도로 설치하라는 뜻이 아닙니다. EXE 방식으로 배포받거나 기관 담당자가 누락·격리를 확인해야 합니다.

예: `D001 / P001 / 2026 / 시행예산 / 시행예산 / 전체 / 사업총액 / 전체`에서 한글 `1,000 천원`과 엑셀 `1000000 원`은 표준값 `1000000 KRW`로 같습니다. `KRW`는 원화의 표준 표시입니다. 한글 쪽만 확인하면 여전히 연결 확인이 필요합니다.

## 자동 가상시험

폴더형 ZIP을 쓰는 경우 **가상시험.cmd를 그냥 더블클릭**합니다. 단일 EXE 사용자는 우선 **가상자료로 시작**으로 화면에서 시험하세요. 내장 자동 시험 스크립트는 EXE가 준비한 프로그램 폴더에도 있으며 기관 담당자가 실행할 수 있습니다. 관리자 권한이면 중단합니다. 결과는 일반 사용자 폴더 `%LOCALAPPDATA%\BudgetOffline\selftest-results` 아래 새 폴더에 저장하며, 끝나면 실제 경로를 표시합니다. 프로그램 설치 폴더에 쓰기 권한을 요구하지 않습니다. 이 시험은 가상 정답에 대해 확인·승인 작업을 코드로 수행합니다. 실제 사용자 승인이나 사람이 한 정답 검수는 아닙니다. 실패한 항목이 있으면 실제 업무자료를 사용하지 마세요.

Linux 개발 환경에서는 다음을 터미널에 입력합니다. 명령을 실행할 위치는 저장소 최상위 폴더입니다.

```sh
python -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
.venv/bin/python tools/selftest.py test-results-new --departments 52
.venv/bin/python run_app.py
```

개발용 의존성 설치에는 인터넷이 필요합니다. 완성된 Windows 묶음의 업무 실행에는 필요하지 않습니다. `--departments 52`는 52개 부서의 작은 가상파일을 새로 만들어 시험합니다. 결과 위치는 기존 폴더와 겹치지 않아야 합니다.
